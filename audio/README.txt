HO ZON - PORTAL AMBIENT MUSIC
─────────────────────────────

Untuk mengaktifkan musik latar belakang (ambient music) katedral pada portal teologi Ho Zon:

1. Siapkan file musik pilihan Anda dalam format MP3 (misalnya lagu Gregorian Chant atau Ambient Drone).
2. Ubah nama file MP3 tersebut menjadi "ambient.mp3" (huruf kecil semua).
3. Letakkan/salin file "ambient.mp3" ke dalam folder "audio" ini.

Setelah file diletakkan di sini, musik latar akan berbunyi secara sempurna dan lancar, baik saat dijalankan di server lokal (localhost) maupun setelah diunggah ke internet, tanpa adanya hambatan pemblokiran internet (CORS/hotlinking/sensor ISP).
